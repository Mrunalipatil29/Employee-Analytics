#  Employee Analytics

## Project Overview

This project analyzes employee data to understand workforce distribution, salary, employee performance, training, experience, and resignation patterns.
The project uses Excel, SQL, Python, and Power BI to perform data cleaning, analysis, visualization, and generate business insights.

##  Project Objectives

* Analyze employee workforce distribution
* Understand salary patterns across departments and job roles
* Analyze employee performance
* Study training hours and performance
* Analyze employee resignation patterns
* Understand employee age and experience distribution

##  Tools & Technologies

* Excel – Data cleaning, analysis, and dashboard
* SQL – Data querying and business analysis
* Python – Exploratory Data Analysis (EDA)
* Pandas – Data manipulation
* Matplotlib & Seaborn** – Data visualization
* Power BI – Interactive dashboard and visualization

* Workforce distribution varies across departments.
* Average salary differs across departments and job titles.
* Employee performance varies across departments.
* Training hours can be compared with performance to understand employee development.
* Resignation patterns vary across departments and can help HR identify areas requiring attention.
